# Auto Media - Frontend

React + Vite dashboard.

## Setup

1. `npm install`
2. Copy `.env.example` to `.env` and set `VITE_API_URL` to your backend URL.
3. `npm run dev`

## Pages (Phase 1)

- `/login`, `/register` — email/password + "Continue with Google"
- `/connect-sheet` — paste a Google Sheet URL, map its columns
- `/dashboard` — live view of videos read from the connected sheet
- `/settings` — account info, disconnect sheet
